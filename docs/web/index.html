Wi-Fi motion sensing

Sense motion with the Wi-Fi already there.

When people move, they change the Wi-Fi signal. ESPectre reads those changes and reports motion. You just need an ESP32 and the router you already own.

Privacy first

Motion without
images or audio.

ESPectre derives motion from changes in the Wi-Fi channel. It does not collect images or audio, which makes the sensing boundary easier to explain in shared spaces such as schools, gyms, offices, public venues, and places of worship. See how it works →

Built to embed

Add motion sensing to your product.

ESPectre’s C++ SDK adds local motion sensing to ESP32 products without cameras or dedicated radar hardware. OEMs can choose Lightweight Detection when CPU and working memory are tight, or High-Accuracy Detection when detection quality is the priority. Explore the SDK →
